# Bloom Nail Bar

Website for a nail salon.

![Preview](.github/preview.jpg)

**Live:** [bloom-nail-bar-zeta.vercel.app](https://bloom-nail-bar-zeta.vercel.app)

## Stack

Next.js, TypeScript, Tailwind CSS, GSAP, Framer Motion

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.
